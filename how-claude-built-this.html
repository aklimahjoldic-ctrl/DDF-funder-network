How Claude built this

A record of how the DDF Funders Network was made through conversation with Claude, an AI model by Anthropic, for a class assignment on vibe coding. AJ gave directions in plain English; Claude did the research, wrote the code, checked the facts, and published the result. Built 26 Nov 2026.

The steps

  1. Research. Claude searched dorisduke.org and the wider web for programs where several funders pooled money with the Doris Duke Foundation (DDF), starting from AJ's example, Humanity AI. "Search the Doris Duke website and the internet to find all the instances of grant programs in which multiple funders pooled funds together."
  2. Spreadsheet. The findings went into an Excel workbook organized by DDF program area, with tabs for pooled programs, a summary by area, aligned efforts that weren't true pools, collaboratives checked where DDF wasn't named, and notes. Built with Python and openpyxl.
  3. Static network chart. A first spring-layout (force-directed) chart in Python with networkx and matplotlib. Funders are nodes; line width shows the size of the shared pool; funders in the same program are linked with lighter lines so they cluster together. "Make the nodes funders, edges the size of the funding, and the layout spring. Keep the style minimalist."
  4. Interactive page. The chart was rebuilt in the browser with D3.js: a live force simulation with a year filter and Play timeline, DDF program filters, dots sized by endowment and colored by program, hover and click details, zoom, and a side panel listing funders and programs.
  5. Design iterations. About a dozen rounds of feedback shaped the details. Examples: softer hover bolding, a one-time pulse on the DDF node as a "click me" hint, the big year shown during playback, lighter labels for single-program funders, a program dropdown and Reset button, clickable program names, and website links in the funder panel. Each change was checked with automated browser screenshots before publishing. "What if users don't discover that nodes are clickable? Can you suggest a hint or affordance?"
  6. Publishing. The page is published as a Claude artifact, pushed to a private GitHub repository, and copied to AJ's Mac.
  7. Fact-check. AJ asked Claude to make sure everything shown is accurate. Claude re-read every program's primary source, checked 46 funder websites, replaced endowment estimates with IRS Form 990 figures, and fixed what didn't hold up. "Make sure you are showing accurate and verified information everywhere here."
  8. Confidence ratings and audit. Every program and endowment got a 1–4 confidence rating, shown in the page's info boxes and the spreadsheet. A separate fresh checker then re-verified a random sample of items rated 4. "Evaluate the accuracy of what you have from 1-4. 4 being the highest checked, accurate, verified."

Sources and tools

  • Primary sources: DDF news releases and project pages; partner pages and releases (MacArthur, NEFA, Artist Relief, The New York Community Trust, William T. Grant Foundation, Land Trust Alliance); IRS Form 990 and 990-PF filings through ProPublica Nonprofit Explorer.
  • Secondary sources (used only where no primary source was found, and rated 2): Chronicle of Philanthropy, Mongabay, Inside Philanthropy, Wikipedia.
  • Code: Python (openpyxl, networkx, matplotlib) for the spreadsheet and static chart; HTML, CSS and D3.js v7 for the interactive page; Playwright for automated screenshot tests; Git and GitHub for version control.
  • AI: Claude, working in Claude Code. Claude used web search, web page reading, and helper agents that fetched pages in parallel.

Independent audit

A fresh checker that hadn't seen any of this work re-read the cited source for a random sample of 10 items rated 4: 7 endowment figures and 3 programs (National Dance Project, Artist Relief, and the Collective to Strengthen Pathways for Health Research). It was told to check every number, date and name.

Result: 10 of 10 matched, with no partial matches or mismatches. Four endowment figures match after rounding (for example, $885.7M is shown as $886M). The checker also noted two nuances, which are now in the notes: the Collective's page adds "additional philanthropic partners" beyond the nine named, and NEFA is changing its national programs after the final Production Grant cohort in September 2026.

What the fact-check changed

  • Endowments: estimates from Wikipedia and memory were replaced with total assets from the latest IRS 990 filings, with the fiscal year shown. Some moved a lot: Ford went from $13.7B to $17.5B, Open Society from $19.6B to $10.8B, and Bloomberg from $4.2B to $12.1B. Open Society and Bloomberg are rated 3 because each 990 covers one main foundation, not the whole network. Stavros Niarchos files no US 990, so its Wikipedia estimate stays and is rated 2.
  • Artists Make Technology: DDF's launch release names Mozilla, Hewlett and Ford, not MacArthur or Omidyar Network. Those two come from a later news report, so the program is rated 3. The pool is now shown as an $11M goal with $6.5M committed at launch.
  • Tribal Nations Conservation Pledge: DDF's release confirms $102.5M and DDF's own $32M share, but it doesn't name the other 14 funders. Their names come from news reports, so the program is rated 2.
  • Fund to Retain Clinical Scientists: the release states the grant size two ways ($500K and $550K). The page now shows $550K, which matches the $12.1M total, and no longer shows a guessed end year.
  • Land and Climate Program: the guessed 2021 start was removed, because the source is undated. Only DDF's dated 2024 grant is shown.
  • Mosaic Network and Fund: it's now marked as paused, not ended, and all 11 donors shown were confirmed on its donor list.
  • Institutional Challenge Grants: Annie E. Casey joined only the 2026 round. The 2023 and 2025 rounds were confirmed from W.T. Grant Foundation releases.
  • Performing Artist Recovery Fund: The New York Community Trust ran the fund, but the release doesn't say it added its own money. This is flagged in the note.
  • Collective for Health Research: renamed to its official name, the Collective to Strengthen Pathways for Health Research.
  • Websites: 45 of 46 links load and go to the right organization. The Howard Gilman Foundation link couldn't be checked, so it was removed.

Security and privacy review

  • Outside code: the page loads exactly two things from outside: D3.js version 7.9.0 from cdnjs.cloudflare.com, pinned to that exact version, and the Inter and Space Grotesk fonts from Google Fonts. Everything else is written inline in the page.
  • No data collection: there are no forms, cookies, analytics, trackers, or logins. The page stores nothing in the browser and sends nothing anywhere.
  • No secrets: no API keys or credentials appear in the page or the repository. The data is public information from public sources.
  • Links: external links open in a new tab with rel="noopener", so the linked site can't control this page.
  • Private by default: the GitHub repository is private, and the artifact is visible only to people AJ shares it with.

Limits

  • DDF rarely publishes its own share of a pool, so line widths use each program's total pool, not DDF's contribution. Claude tried to read DDF's own grant payments from its IRS 990-PF grant lists, but the filing viewer couldn't be read automatically, so DDF's share is shown only where a release states it.
  • DDF's online grants database lists 132 grants, but only about 20 could be read automatically, so smaller collaboratives may be missing.
  • Endowments are 990 book values, which can differ from the market values foundations report themselves.
  • The ratings show how well each fact is sourced. They don't guarantee the sources themselves are right.
