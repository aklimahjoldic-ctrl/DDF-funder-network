# DDF Funders Network

An interactive network of the funders that pooled money with the Doris Duke Foundation (DDF) on 13 pooled or co-funded grant programs. It was built for a class assignment.

- `index.html`: the interactive D3 network. It's a static page, so open it in a browser or deploy it as-is (it works on Vercel with no build step).
- `how-claude-built-this.html`: how the project was made with Claude, the sources, the 1–4 confidence ratings, the independent audit and a security review.
- `DDF_Pooled_Fund_Programs.xlsx`: the research spreadsheet, with sources and a 1–4 confidence rating for every row and endowment figure.
- `DDF_funder_network.png` and `ddf_funder_network.py`: the static version of the chart and the script that draws it.

Every program and endowment figure was fact-checked on 26 Nov 2026. Endowments are total assets from each funder's latest IRS 990 filing (ProPublica Nonprofit Explorer). Each item carries a 1–4 confidence rating with its source.
