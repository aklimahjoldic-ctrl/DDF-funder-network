# DDF Funders Network

An interactive network of the funders that pooled money with the Doris Duke Foundation (DDF) on 13 pooled or co-funded grant programs. It was built for a class assignment.

- `index.html`: the interactive D3 network. It's a static page, so open it in a browser or deploy it as-is (it works on Vercel with no build step).
- `DDF_Pooled_Fund_Programs.xlsx`: the research spreadsheet, with sources.
- `DDF_funder_network.png` and `ddf_funder_network.py`: the static version of the chart and the script that draws it.

Endowment figures are a mix of sourced and approximate values. The notes on the page explain which is which.
